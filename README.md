# 韓國入境管制藥品查詢

查詢臺灣藥品許可證是否有效、是否含韓國《麻醉藥品管理法》管制成分（入境韓國須事先申請許可）。

- 線上使用：啟用 GitHub Pages 後瀏覽
- 查詢方式：許可證字號（只輸數字即可）／中文品名關鍵字

## 資料來源

- 衛生福利部食品藥物管理署「全部藥品許可證資料集」（data.gov.tw #9122，每週更新）
- 駐韓國台北代表部釜山辦事處公告之韓國《麻醉藥品管理法》管制成分清單（481 種）

兩者交叉比對，僅保留許可證有效（未註銷、未過期）且含管制成分之藥品。

## 免責

本頁僅供出國前自我檢查參考，許可證狀態以食藥署最新公告為準；攜帶管制藥品入境韓國請依韓國法規事先申請許可。用藥請遵醫囑。
