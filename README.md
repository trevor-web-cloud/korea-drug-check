# 韓國入境管制藥品查詢

查詢臺灣藥品許可證是否有效、是否含韓國《麻醉藥品管理法》管制成分（入境韓國須事先申請許可）。

- 線上使用：https://trevor-web-cloud.github.io/korea-drug-check/
- 查詢方式：許可證字號（只輸數字即可）／中文品名關鍵字／英文品名關鍵字
- 介面語言：繁體中文／English／Bahasa Indonesia（右上角切換，順序：中、EN、ID、日本語，自動記憶）；搜尋條件維持中文品名與英文品名
- 目前收錄：1,084 筆（資料基準 2026-10-31，每週六自動更新）

## 資料來源

- 衛生福利部食品藥物管理署「全部藥品許可證資料集」（data.gov.tw #9122，每週更新；本次以 24,874 筆有效許可證比對）
- 駐韓國台北代表部釜山辦事處公告之韓國《麻醉藥品管理法》管制成分清單（481 種）
- 韓國關稅廳〈법률에서 정하는 마약류 성분〉之管制成分清單（481 種，第二來源交叉驗證）

兩者交叉比對，僅保留許可證有效（未註銷、未過期）且含管制成分之藥品。查無結果表示該藥品未含韓國公告管制成分，或其許可證已註銷／過期。

## 日文版：日本製藥品查詢

查詢日本製藥品（含市販藥）是否含韓國管制成分。

- 線上使用：https://trevor-web-cloud.github.io/korea-drug-check/ja/
- 查詢方式：成分名（羅馬拼音自動轉片假名／日文／英文／中文）／藥品名（英文或市販藥品牌名）
- 目前收錄：210 種管制成分、354 種處方藥、1,195 件市販藥品牌（資料每兩個月更新）
- 未輸入關鍵字時顯示 210 種成分一覽，可點選瀏覽

### 資料來源

- KEGG DRUG 資料庫（12,899 筆藥品）× 韓國管制成分（481 種）比對 → 354 筆命中，210 種不重複成分
- 210 種成分之日文名：166 種經 Wikidata 取得片假名，其餘以英文查詢
- 市販藥品牌：PMDA「一般用医薬品・要指導医薬品検索」5 種高風險成分 CSV（アリルイソプロピルアセチル尿素 145 件、デキストロメトルファン 169 件、ジヒドロコデイン 397 件、コデイン 399 件、プソイドエフェドリン 85 件）

## 免責

本頁僅供出國前自我檢查參考，許可證狀態以食藥署最新公告為準；攜帶管制藥品入境韓國請依韓國法規事先申請許可。用藥請遵醫囑。
