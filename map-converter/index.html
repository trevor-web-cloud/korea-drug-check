Naver ↔ Google 地圖座標轉換 · 左右對照

左邊 Google，右邊 Naver。改一邊，另一邊自動跟著算。不用開對方連結，理論計算就夠。有店名用店名搜尋最簡單；要精確圖釘才用座標。

① 貼上任一邊的連結 / 座標，自動解析

小提醒：naver.me/... 短連結本身沒有座標，網頁無法直接解。先在瀏覽器打開它一次，讓它跳轉成完整 map.naver.com/... 連結，再把完整連結貼到上面。Google 的 maps.app.goo.gl/... 短連結也一樣，要先打開展開。

Naver Map ▶c= · EPSG:3857 公尺

Naver 網頁網址的 c= 不是經緯度，是 Web Mercator EPSG:3857 投影座標，單位是公尺，順序是 X,Y = 經度方向,緯度方向。

—
在 Naver Map 開啟
—

App 連結格式：nmap://place?lat=緯度&lng=經度&name=名稱&appname=...（appname 必帶，否則會靜默失敗）

理論計算公式

Google → Naver：x = 經度 × 20037508.34 / 180；y = log(tan((90+緯度)×π/360)) / (π/180) × 20037508.34 / 180

Naver → Google：經度 = X × 180 / 20037508.34；緯度 = atan(exp(Y×π/20037508.34)) × 360/π - 90

使用方式

  1. 有店名：直接在上面填店名（韓文名最穩），兩邊都會產生搜尋連結，點開即是同一間。
  2. 要精確圖釘：左邊填 緯度,經度，右邊自動算出 c= X,Y；或右邊填 X,Y，左邊自動算回經緯度。
  3. 只有一邊的分享連結：貼到最上面解析。Google 連結取 @緯度,經度；Naver 連結取 c= X,Y 再轉。

不捏造座標：只顯示你輸入 / 解析出來的座標。沒有精確座標時，請用店名 / 地址搜尋連結，並在現場以地址再確認一次。
