Naver ↔ Google 地圖座標轉換 · 左右對照

左邊 Google，右邊 Naver。改一邊，另一邊自動跟著算。不用開對方連結，理論計算就夠。有店名用店名搜尋最簡單；要精確圖釘才用座標。

① 貼上任一邊的連結 / 座標，自動解析

小提醒：naver.me/...、maps.app.goo.gl/... 短連結本身沒有座標，純前端網頁無法直接解（需跟隨跳轉，瀏覽器會擋 CORS）。請按解析區的「在新分頁打開短連結展開」，等跳轉成完整連結後，複製網址列的完整連結再貼回來。完整連結通常含 @緯度,經度 或 !3d緯度!4d經度 或 c= X,Y。

Naver Map ▶c= · EPSG:3857 公尺

Naver 網頁網址的 c= 不是經緯度，是 Web Mercator EPSG:3857 投影座標，單位是公尺，順序是 X,Y = 經度方向,緯度方向。

iPhone：nmap://place?lat=緯度&lng=經度&name=名稱&appname=網頁URL（appname 必帶，網頁版必須填本頁 URL）
Android：intent://place?...#Intent;scheme=nmap;package=com.nhn.android.nmap;S.browser_fallback_url=Play商店;end（Chrome 直接點 nmap:// 常常沒反應，必須用 intent:// + package + 備援）

⚠️ 如果在 Muse / KakaoTalk / LINE 內建瀏覽器點 App 連結沒反應：請先點瀏覽器的「分享 → 在 Safari / Chrome 開啟」，再回來點 App 連結。In-app browser 不支援 nmap:// / intent:// 跳轉。未安裝 Naver Map 時：iPhone 請至 App Store 安裝 NAVER Map；Android 請至 Google Play 安裝 NAVER Map。

最穩的替代做法（不用 App 連結）：在 Safari 打開上面的 Naver 網頁連結，再點網頁裡的「App에서 보기 / Open in App」；或直接在 Naver Map App 搜尋框貼韓文店名 / 地址。

理論計算公式

Google → Naver：x = 經度 × 20037508.34 / 180；y = log(tan((90+緯度)×π/360)) / (π/180) × 20037508.34 / 180

Naver → Google：經度 = X × 180 / 20037508.34；緯度 = atan(exp(Y×π/20037508.34)) × 360/π - 90

使用方式

  1. 有店名：直接在上面填店名（韓文名最穩），兩邊都會產生搜尋連結，點開即是同一間。
  2. 要精確圖釘：左邊填 緯度,經度，右邊自動算出 c= X,Y；或右邊填 X,Y，左邊自動算回經緯度。
  3. 只有一邊的分享連結：貼到最上面解析。Google 連結取 @緯度,經度；Naver 連結取 c= X,Y 再轉。

不捏造座標：只顯示你輸入 / 解析出來的座標。沒有精確座標時，請用店名 / 地址搜尋連結，並在現場以地址再確認一次。

自我檢查（Android / iPhone 都要能開）

  1. 網頁：iPhone Safari + Android Chrome 開本頁都應 200，左右兩欄都顯示範例座標。用分享 → 在 Safari / Chrome 開啟，不要停在 Muse / KakaoTalk / LINE 內建瀏覽器。
  2. Google App：iPhone 點「iPhone：Google Maps App」應跳 Google Maps App（comgooglemaps://）；Android 點「Android：Google Maps App」應跳 Google Maps App（geo:），或點網頁連結由系統跳 App 選擇。
  3. Naver App：iPhone 點「iPhone：Naver App」應跳 Naver Map App（nmap://place，Safari 內）；Android 點「Android：Naver App」應跳 Naver Map App（intent://place…#Intent;scheme=nmap;package=com.nhn.android.nmap，Chrome 內；未安裝時導 Play 商店）。
  4. 網頁備援：App 沒反應時，改點「Naver 網頁開啟 (c=)」/「Google Maps 開啟」，在網頁裡再點 App 橫幅；或直接在 App 搜尋框貼韓文店名 / 地址。
